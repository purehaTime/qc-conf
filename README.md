# qc-conf — панель для niri на Quickshell

Модульная конфигурация [Quickshell](https://quickshell.org) 0.3 в пастельной палитре
[Catppuccin](https://catppuccin.com): верхняя панель с управлением плеером, метриками
системы и системным блоком (звук, сеть, Bluetooth, яркость, раскладка, буфер обмена, тема).

```
┌────────────────────────────────────────────────────────────────────────────┐
│ ♪ трек  ⏮ ⏸ ⏭ 🔇          CPU  RAM  GPU          [ системный блок ]  HH:mm │
└────────────────────────────────────────────────────────────────────────────┘
```

Писалось под niri, но специфичен для него только индикатор раскладки (`niri msg`) —
остальное работает на любом Wayland-композиторе с поддержкой `wlr-layer-shell`.

## Установка

```bash
git clone https://github.com/purehaTime/qc-conf ~/.config/quickshell/niri
qs -c niri
```

Каталог можно назвать иначе — тогда меняется имя после `-c`. Или запускать по пути:
`qs -p /путь/к/qc-conf`.

Автозапуск и бинды в `~/.config/niri/config.kdl`:

```kdl
spawn-at-startup "qs" "-c" "niri"

binds {
    XF86AudioRaiseVolume  allow-when-locked=true { spawn "qs" "-c" "niri" "ipc" "call" "audio" "up"; }
    XF86AudioLowerVolume  allow-when-locked=true { spawn "qs" "-c" "niri" "ipc" "call" "audio" "down"; }
    XF86AudioMute         allow-when-locked=true { spawn "qs" "-c" "niri" "ipc" "call" "audio" "mute"; }
    XF86MonBrightnessUp   { spawn "qs" "-c" "niri" "ipc" "call" "brightness" "up"; }
    XF86MonBrightnessDown { spawn "qs" "-c" "niri" "ipc" "call" "brightness" "down"; }
    XF86AudioPlay         { spawn "qs" "-c" "niri" "ipc" "call" "media" "playPause"; }
    Mod+V                 { spawn "qs" "-c" "niri" "ipc" "call" "popup" "toggle" "clipboard"; }
}
```

Цели IPC: `popup` (open / close / toggle / list), `audio`, `brightness`, `media`, `theme`.
Проверить вручную:

```bash
qs -c niri ipc call theme cycle
```

## Зависимости

Обязательно — `quickshell` и три шрифта:

```bash
pacman -S quickshell ttf-material-symbols-variable adwaita-fonts ttf-jetbrains-mono-nerd
```

По желанию: `cliphist` + `wl-clipboard` (история буфера), `ddcutil` (яркость внешних
мониторов по DDC/CI), `brightnessctl` (подсветка ноутбука), `pavucontrol`,
`nm-connection-editor`, `blueman` (кнопки «настройки» в док-окнах).

Для DDC/CI нужен модуль `i2c-dev` и членство в группе `i2c`. Сеть и Bluetooth идут через
NetworkManager и BlueZ — используются нативные модули Quickshell, отдельных демонов не надо.

## Возможности

**Слева — плеер (MPRIS).** Обложка, название, кнопки назад / пауза / вперёд / заглушить.
Колесо мыши на названии — переключение треков, ПКМ — пауза. Клик открывает док-окно
с перемоткой, громкостью плеера и выбором проигрывателя. Длинное название едет бегущей
строкой с мягкими краями (`components/MarqueeText.qml`).

**Центр — метрики.** CPU (цвет меняется по нагрузке), занятая память, загрузка GPU
(`nvidia-smi`, при отсутствии — amdgpu из sysfs). При наведении краткая сводка, по клику —
подробности: температуры, swap, видеопамять и топ процессов.

**Справа — системный блок.**

| Кнопка | Наведение | Клик | Колесо / СКМ |
|---|---|---|---|
| Раскладка | текущая раскладка | список раскладок | переключение |
| Буфер обмена | число записей | история cliphist, клик — скопировать, ✕ — удалить | — |
| Яркость | текущий % | слайдеры по мониторам | ±5 % |
| Звук | громкость и устройство | вывод, микрофон, выбор устройств | ±2 %, СКМ — mute |
| Bluetooth | что подключено | питание, поиск, устройства, заряд | СКМ — вкл/выкл |
| Сеть | SSID и сигнал | список Wi-Fi, проводное, настройки | СКМ — Wi-Fi вкл/выкл |
| Тема | текущий вариант | 4 варианта Catppuccin + акцент + светлая/тёмная | смена варианта |

**Часы** — `HH:mm` и дата, по клику календарь на месяц.

Выбранная тема и акцент сохраняются в `~/.local/state/quickshell/by-shell/<id>/theme.json`.

## Настройка

Quickshell перечитывает конфиг при сохранении файла, поэтому всё ниже подбирается вживую:
правите — и сразу видите результат.

**Масштаб панели** — одна константа:

```qml
// config/Settings.qml
readonly property real scale: 1.0   // 1.25 — крупнее, 0.9 — плотнее
```

Через неё проходят все размеры: кегли, иконки, высота панели, отступы, скругления и ширина
док-окон (хелпер `Appearance.px()` в `config/Appearance.qml`).

**Ширина названия трека** — сколько пикселей отдать тексту, прежде чем он поедет строкой:

```qml
// config/Settings.qml
readonly property int mediaTextMaxWidth: 400
```

Рядом — скорость прокрутки, пауза перед стартом и разрыв между повторами (`marqueeSpeed`,
`marqueePause`, `marqueeGap`). Намеренно не масштабируется: это ширина под конкретный экран.

Остальное там же в `config/Settings.qml`: формат часов и локаль, интервалы опроса, шаги
громкости и яркости, внешние программы, список мониторов для панели.
Цвета — `config/Theme.qml`, базовые размеры и анимации — `config/Appearance.qml`.

## Структура

| Каталог | Что внутри |
|---|---|
| `shell.qml` | точка входа: панель на каждом мониторе + IPC |
| `config/` | `Theme` (цвета), `Appearance` (размеры/шрифты/анимации), `Settings` (поведение) |
| `services/` | синглтоны-источники данных: система, звук, яркость, сеть, BT, раскладка, буфер, плееры |
| `components/` | переиспользуемые элементы: кнопка, подсказка, док-окно, слайдер, переключатель, строка списка |
| `modules/bar/` | сама панель по зонам: `media/`, `stats/`, `clock/`, `tray/` |
| `modules/IpcActions.qml` | внешние команды для биндов |

Каждый элемент системного блока — отдельный файл в `modules/bar/tray/`; содержимое его
док-окна описано прямо там же (дети `TrayItem` попадают в попап). Чтобы добавить свою
кнопку, достаточно нового файла и одной строки в `TrayCluster.qml`.

## Заметки по реализации

Ось `FILL` переменного шрифта Material Symbols в Qt рендерится с артефактами, поэтому
«залитость» иконок передаётся насыщенностью начертания (`wght`) — см.
`components/MaterialIcon.qml`.

Если у открытого док-окна меняется размер (догрузился список, изменилось содержимое), под
KWin его поверхность перестаёт получать новые кадры и содержимое застывает. Обход — на пару
кадров прячем окно, поверхность пересоздаётся (`components/DockPopup.qml`). Если на вашем
композиторе такого нет, выключите `Settings.popupRemapOnResize` — попап перестанет моргать
при изменении размера.

Док-окно закрывается через 0.7 с после того, как курсор ушёл и с кнопки, и с самого окна;
повторный клик по кнопке тоже закрывает. Одновременно открыт только один попап.

## Планы

Рабочие столы niri, системный трей приложений (StatusNotifier), уведомления, поиск по
истории буфера, ввод пароля Wi-Fi, батарея и профили питания, лаунчер, обои.
